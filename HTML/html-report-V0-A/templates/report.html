通用技术报告模板
基于 html-report-V0-A skill 生成；正文底色白/无色，系统默认字体。

概述与方法

本文件是 html-report-V0-A skill 生成的报告模板。删除示例内容、替换为你的正文即可。所有交互（目录、折叠、图片查看、引用预览）由 _shared/js/*.js 自动提供，无需手工编写。

设计目标与范围

正文要点：使用白色/无色底色（3.3）、系统默认字体（3.5）、正文宽度随视口变化不设上限（3.7）。

说明：标题由 JS 自动编号（3.2），无需手工写"1.1"；交叉引用用 §1.1 或文档内锚点链接（见 第二节）。

关键词高亮 mark.key

用 <mark class="key"> 标记正文重点词，如：本方案以 demand 命中预取行 为核心统计口径，低面积开销 为实现约束。

提示块五态

默认：普通补充说明。

说明（note）：定义、背景、上下文、引用来源。如：§2 给出本方案的体系结构背景。

提示（tip）：技巧、推荐做法、最佳实践。如：建议先阅读 §1 再进入方案比较。

注意（warning）：潜在风险、局限、易错点。如：面积估算未含 DFX 开销。

禁止（danger）：错误、禁止项、严重风险。如：不得在正文内指出上一版本错误（3.11）。

标题竖条分级（3.18）

一级标题为蓝色粗竖条（h1）；二级标题为浅蓝竖条（h2）；三级为灰色细竖条（h3）；四级为最细灰条（h4）。本页各级标题即为示例。

目录分级字号递减

侧边目录从 H4 起字号递减（11.5px / 10.5px）并弱化颜色，便于长文档辨识层级（见 report.css .toc-item[data-level] 规则）。
