# 测试用例与验收清单（html-report-V0-A）

> 交付前逐项核对；标注【自动】的由 `scripts/validate.py` 覆盖，标注【人工】的需浏览器/目测。
> 目标：让未来 AI 拿到本 skill 后能"复制即用、无需思考"，故用例尽量可脚本化。

---

## A. 脚手架与结构（规则 6）

- [A1]【自动】`python3 scripts/scaffold.py demo /tmp/x` 生成 `demo/` 含 `_shared/`、`demo.html`、`CHANGELOG.md`、`DEV_DOC.md`。
- [A2]【自动】`validate.py` 对生成物输出 ALL PASS。
- [A3]【人工】`demo.html` 在浏览器打开无控制台报错；目录/折叠/查看器均可用。

---

## B. 目录（规则 2.1–2.8）

- [B1]【人工】侧边栏 `#toc-list` 与移动端 `#mobile-toc-list` 均由 JS 从正文标题动态生成（无手工静态 nav 残留）。
- [B2]【人工】超长标题在侧边栏截断为省略号（2.2）。
- [B3]【人工】滚动页面时高亮项随动，且侧边栏自动滚动使高亮项居中（2.3/2.6）。
- [B4]【人工】切换"固定级别/滚动级别"下拉，目录层级随设置变化（2.8）。
- [B5]【人工】折叠某章节标题后，目录高亮不漂移、可正常回跳（2.6）。
- [B6]【人工】视口 ≤768px 时侧边栏隐藏、显示右下目录 FAB（☰），正文宽度自动占满（2.7）。
- [B7]【人工/自动】移动端目录面板 `.mobile-toc-panel` **固定占据视口下方**（`position:fixed; bottom:0`），默认滑出视口外（`translateY(100%)`），点击 FAB 后 `translateY(0)` 滑入且**可折叠**（再点 FAB 或点 ✕ 关闭）（2.7）。检查：宽屏下面板不可见、不占据文档流；窄屏下固定底部、可开合。
- [B8]【人工】文档主标题（`.doc-title`）为 `<div>` 而非 `<h1>`，**不进入目录、不被自动编号**（如不应出现"1 通用技术报告模板"）；章节标题 `h1/h2/h3` 正常编号（3.2/3.2a）。

---

## C. 模态查看器（规则 1.1–1.10，调用 `modal-image-viewer-skill`）

- [C1]【人工】每个 `figure.diagram` 有"查看"按钮，点击进入模态（查看器实现来自 `modal-image-viewer-skill`，按名字调用）。
- [C2]【自动+人工】模态背景**完全透明**（覆盖该 skill 默认深色遮罩），能同时看到图片与底层正文（1.2）。检查 `.img-modal{background:transparent !important}` 生效、无 `rgba(0,0,0,.55)` 残留。
- [C3]【人工】图形区白底 + 20px padding + 圆角（1.4）；缩放时不出现 max-width/height 截断（1.3）。
- [C4]【人工】header（标题+‹/›+✕+缩放）浮于图片上方、半透明（1.7）。
- [C5]【人工】+/-/重置按钮、滚轮缩放、鼠标拖拽平移均生效（1.6）。
- [C6]【人工】点击图片外空白区域、点 ✕、按 ESC 均可关闭（1.5）。
- [C7]【人工】多图时 ‹/› 切换；首图 ‹ disabled、末图 › disabled（1.8）。
- [C8]【人工】打开后整图完整显示，一维铺满视口、另一维在视口内，使用 SVG 真实尺寸（1.9）；**无灰底白字**（克隆渲染正确）。
- [C9]【自动】`grep -oP 'id="fig-[^"]*"' demo.html | sort | uniq -d` 输出**空**（1.10 figure 级唯一）。
- [C10]【人工】克隆多张图时，SVG 内部 id 经 `deduplicateSvgId` 隔离，样式/marker 互不串扰（1.10）。

## D. 绘图（规则 0.1–0.5）

- [D1]【人工】图中含文字节点为低饱和底色（0.1）。
- [D2]【人工】架构框图连线为直角（0.4），连线有文字注释解释信号/功能。
- [D3]【人工】箭头端点落在框体边沿，无空白区孤点/共享空白 hub（0.3）。
- [D4]【人工】复核连线/箭头方向与意图一致（0.2）。
- [D5]【自动】所有 `figure` id 唯一且带 `fig-<章>-<序号>` 前缀（0.5）。

## E. 正文（规则 3.1–3.14）

- [E1]【人工】代码块默认折叠，点击展开（3.1）。
- [E2]【人工】h1/h2/h3 可点击折叠本层；标题显示自动编号（3.2）。
- [E3]【人工】文档底色白/无色（3.3）；系统默认字体（3.5）。
- [E4]【人工】文内跳转/引用链接 hover 弹出预览（3.4）。
- [E5]【人工】正文宽度随视口变化无上限（3.7）。
- [E6]【人工】正文内 `<style>`/`<div>` 等字面文本已 HTML 实体转义（3.6）。
- [E7]【人工】复核发现的旧版问题以"特别说明"形式强调正确点，正文不直接指责旧版（3.11/3.13）。
- [E8]【人工】结论有明确推理或代码/文档依据（3.14）。

## F. 校验（规则 4.1–4.5 + 版本）

- [F1]【自动】`validate.py` 4.1：`<div>` 开闭数相等。
- [F2]【自动】`validate.py` 4.2：截断行 0。
- [F3]【自动】`validate.py` 4.3：标签平衡无错配。
- [F4]【自动】`validate.py` 4.4：全文档 id 无重复；figure id 前缀合规。
- [F5]【自动】`validate.py` 4.5：`#main` 标题全部有 id（缺失则告警，运行时自动补）。
- [F6]【自动】`validate.py` 版本一致性：`config.js` / `CHANGELOG.md` / `DEV_DOC.md` 版本一致。
- [F7]【人工】`CHANGELOG.md` 有本次变更条目且版本号与 HTML 一致；HTML 正文不含变更记录。

## G. 版本号（规则 5）

- [G1]【自动】HTML 正文仅 `config.js` 一处版本变量 `REPORT_VERSION`；侧边栏/meta 由注入脚本读取填充。
- [G2]【人工】每次修改后版本号已递增（0.01→…→0.99），未擅自加大版本/加后缀。
- [G3]【自动】`CHANGELOG.md` / `DEV_DOC.md` 版本号 == `config.js` 版本号。

---

## H. 失败注入回归（建议 CI）

- [H1] 故意在 html 中删除一个 `</div>` → validate 4.1/4.3 应 FAIL。
- [H2] 故意让两个 figure 同 id `fig-1-1` → validate 4.4 应 FAIL。
- [H3] 故意把 `config.js` 版本改为 `v0.02` 而 CHANGELOG 仍为 `v0.01` → 版本一致性应 FAIL。
- [H4] 故意在行尾写 `</div>` 独占一行且前面无开标签 → 4.2 截断行应捕获（注意：正常闭合 `</div>` 不应被判为截断，校验用 `</\w+\s*$` 仅捕获"行尾恰为结束标签且无后续"的异常；普通闭合因后接换行/内容不命中）。
