# HTML Frontend Known Bugs Catalog v0.01

> 本文档整理自 /NOTE 目录下 5 个文档项目（C910 CIU/L2缓存、GEM5架构仿真、SOC集成、CHI设计实现、CMN-700 TRM）的开发日志和变更记录，共 40+ 个已修复 bug。
> 每个条目标注了检查器中对应的检测规则名称。

---

## 1. 结构类 Bug

### 1.1 div 标签不配对
- **项目**: C910 CIU/L2缓存 (v0.03, v0.07, v0.13, v0.21)
- **现象**: div 开闭数量不等（829开/828关），或多余 `</div>` 过早关闭 `<div id="main">`
- **根因**: 章节合并时 sec2-1 提前关闭、sec2-4 缺失闭合；内容重建时游离 div 序列
- **检查器规则**: `div标签配对`、`stray闭合标签检测`、`游离div序列检测`

### 1.2 article 标签未闭合/位置错误
- **项目**: C910 CIU/L2缓存 (v0.03, v0.12)
- **现象**: `</article>` 闭合标签缺失或位置错误
- **检查器规则**: `article标签配对`

### 1.3 stray `</code>` 标签
- **项目**: C910 CIU/L2缓存 (v0.12)
- **现象**: code 标签数量不匹配，存在游离的 `</code>` 闭合标签
- **检查器规则**: `code标签配对`、`stray闭合标签检测`

### 1.4 双层 code 标签嵌套
- **项目**: C910 CIU/L2缓存 (v0.09)
- **现象**: 阶段分析表行中 `<code><code>...</code></code>` 双层嵌套
- **检查器规则**: `双层code标签嵌套`

### 1.5 DOM 元素位于 script 之后
- **项目**: C910 CIU/L2缓存 (v0.06)
- **现象**: `#back-to-top`、`#link-tooltip`、`#diagram-modal` 位于 `<script>` 标签之后，导致 `getElementById()` 返回 null
- **根因**: DOM 解析未完成即执行 JS
- **检查器规则**: `DOM元素位置(script前)`

## 2. CSS 类 Bug

### 2.1 模态窗口有色遮罩
- **项目**: C910 CIU/L2缓存 (v0.08, v0.09)
- **现象**: 模态窗口背景为 `rgba(0,0,0,0.85)` 黑色遮罩 → `rgba(255,255,255,0.95)` → `transparent`
- **根因**: 有色遮罩遮挡正文阅读
- **检查器规则**: `模态窗口背景透明`

### 2.2 模态窗口尺寸限制
- **项目**: C910 CIU/L2缓存 (v0.07), GEM5 (v0.04)
- **现象**: `#diagram-modal-content` 设有 `max-width:95vw, max-height:95vh`；GEM5 中 `.img-wrapper` 设有 `max-width:92vw, max-height:88vh, overflow:hidden`
- **根因**: 限制框约束图片无法铺满页面
- **检查器规则**: `模态窗口无尺寸限制`

### 2.3 侧边栏长标题换行
- **项目**: C910 CIU/L2缓存 (v0.08)
- **现象**: 侧边栏长标题换行显示
- **检查器规则**: `侧边栏禁止换行`

### 2.4 章节默认折叠
- **项目**: C910 CIU/L2缓存 (v0.12)
- **现象**: 第三章有 `<h2 class="collapsed">` 和 `style="max-height: 0px;"`，默认折叠
- **检查器规则**: `章节默认展开检测`

### 2.5 响应式级联顺序错误（base 在 @media 之后）
- **项目**: ADS1263 驱动库调研报告 (v0.09)
- **现象**: 窄屏下侧边栏折叠到底部，但正文左侧残留 260px 空白、正文不撑满窗口宽度
- **根因**: 基础（桌面）规则 `#main{margin-left:260px}` 写在 `@media (max-width:980px)` 块**之后**；窄屏时二者同等特异度命中，CSS「后者胜」使基础规则覆盖媒体查询 → `margin-left` 仍为 260px
- **修复**: 将基础规则整体移到 `@media` 块之前（基础先定义、覆盖后定义）
- **检查器规则**: `响应式级联顺序(base须在@media之前)`（仅「同选择器 + 属性值不同 + 基础在 @media 之后」时告警，避免误报）

## 3. JavaScript 类 Bug

### 3.1 内联 JS 块完全缺失
- **项目**: C910 CIU/L2缓存 (v0.12, v0.21), SOC (v0.03)
- **现象**: openDiagramViewer、initScrollSpy、initCollapse 等函数全部缺失；mermaid.min.js 引用也缺失
- **根因**: v0.12 从备份恢复时未包含 JS；v0.21 内容重建时内联 `<script>` 块被整体裁掉
- **检查器规则**: `JS块完整性(script数量)`、`scroll-spy函数完整性`、`框图查看器JS函数`

### 3.2 scroll-spy 完全缺失
- **项目**: CHI 设计实现 (v0.08)
- **现象**: HTML 文件中完全缺失 scroll-spy 的 CSS 样式和 JavaScript 代码
- **检查器规则**: `scroll-spy函数完整性`、`scroll-spy属性存在`

### 3.3 scroll-spy 位置不准确
- **项目**: C910 CIU/L2缓存 (v0.06)
- **现象**: 使用 `offsetTop` 获取位置不准确
- **修复**: 改用 `getBoundingClientRect()`
- **检查器规则**: `scroll-spy函数完整性`（检测 getBoundingClientRect 使用）

### 3.4 折叠后 scroll-spy 位置漂移
- **项目**: GEM5 (v0.04)
- **现象**: `initScrollSpy()` 只在初始化时一次性计算 offsetTop，折叠章节后位置变化但高亮仍使用旧位置
- **检查器规则**: `scroll-spy重计算(折叠后)`

### 3.5 Mermaid 异步渲染时序
- **项目**: GEM5 (v0.03)
- **现象**: `mermaid.run()` 是异步调用，未等待完成即设置图片查看功能
- **检查器规则**: `Mermaid异步渲染处理`

### 3.6 硬编码重复按钮
- **项目**: CHI 设计实现 (v0.09)
- **现象**: 每个 svg-container 有 2 个硬编码 `<div class="svg-view-btn">` 按钮 + JS 动态创建 1 个 = 3 个按钮，硬编码的无 onclick 不工作
- **检查器规则**: `重复按钮检测`、`硬编码重复按钮检测`

## 5. 框图/图片查看器类 Bug

### 5.1 SVG 在模态查看器中不显示
- **项目**: GEM5 (v0.02, v0.03)
- **现象**: `data:image/svg+xml` URI 编码方式导致 SVG 渲染失败
- **修复**: 改为直接 SVG 元素克隆插入
- **检查器规则**: `SVG容器存在性`

### 5.2 缩放/拖拽功能失效
- **项目**: GEM5 (v0.03, v0.07)
- **现象**: `applyZoom()` 适配 `<img>` 标签而非 `<div>` 容器；`fitToWindow()` 使用 `scrollWidth` 获取 SVG 尺寸但未设置 width 的 SVG 返回 300×150
- **检查器规则**: `图片缩放/拖拽JS`

### 5.3 框图连线/箭头错误
- **项目**: CHI 设计实现 (v0.04)
- **现象**: Mesh 拓扑 MXP 位置错误、设备挂载方式错误、Mesh 链路方向错误
- **检查器规则**: `框图连线复查标记`（人工复查提醒）

### 5.4 Mermaid "Unsupported markdown: list" 错误
- **项目**: C910 CIU/L2缓存 (v0.04)
- **现象**: Mermaid 11.4.1 将标签中以"数字."开头的文本解释为 markdown 有序列表
- **修复**: 将编号标签改为破折号分隔
- **检查器规则**: `Mermaid标签兼容性`、`Mermaid渲染兼容性`

## 8. 检查器自身误报规避经验（v0.02）

针对检查器在 ADS1263 报告 v0.09 复检中暴露的 3 个误报 + 1 个跨选择器误报（初版响应式检查），已在 v0.02 修复，记录以便维护：

### 8.1 锚点 `oldId` 误报（扫描含 JS 注释）
- **现象**: 报告 `deduplicateSvgId()` 内注释 `// href="#oldId"` 被正则误判为「断裂锚点：oldId」
- **修复**: `extract_id_matches` / `extract_href_anchors` 扫描前先 `strip_script_style()` 去除 `<script>`/`<style>` 块
- **原则**: 标签/锚点扫描必须排除代码与样式块，否则注释与 CSS 选择器会被误匹配

### 8.2 scroll-spy 硬编码 `initScrollSpy` 误报
- **现象**: 报告用 `function spy()` + `addEventListener('scroll', spy)` 实现滚动高亮，却被判定「缺少定义 function initScrollSpy」为 fail
- **修复**: 新增 `detect_scrollspy()`（多候选函数名 + scroll监听/高亮切换/rect定位 启发式）；相关 4 项检查改为 warning 且不依赖特定函数名
- **原则**: 功能检测应基于「机制是否存在」，而非「是否叫某个固定名字」

### 8.3 侧边栏/标题文本比对误报（折叠箭头与缩写）
- **现象**: 标题带折叠箭头 `▾`、导航有意缩写，被判定「文本不一致」fail
- **修复**: 新增 `_norm_nav_text()` 归一化（去空白/箭头/括号/编号前缀），比对改为「归一化相等/互包含/前6字相同」，状态降为 warning
- **原则**: 文本一致性是设计层比对，应容忍排版符号与合理缩写，仅作柔和告警

### 8.4 响应式级联检查须同源选择器（避免跨选择器误报）
- **现象**: 初版响应式检查仅比对属性名，导致 `#main` 与 `.ar` 仅因都含 `margin-left` 就被误报为级联冲突
- **修复**: 改为提取叶子规则块（选择器,属性,值,偏移,是否在@media内），仅「同选择器+同属性+值不同+基础在@media之后」才告警
- **原则**: 级联冲突必须是同一选择器下的规则，跨选择器同名属性不构成冲突
